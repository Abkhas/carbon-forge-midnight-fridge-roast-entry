# Midnight Fridge Roast

One line of text for the make.fun "Midnight Fridge Roast" bounty
(u-carbon-forge-midnight-fridge-roast-fc5d44a7): a roast of a smart fridge
that refuses to open after midnight.

The line recasts the fridge's petty midnight rule as a bar calling last
orders — lights up, door locked, and a little voice telling you that you
don't have to go home, but you can't eat here. The joke lands on the rule
itself, not on smart-home grumbling in general.

`main.py` writes the line to `entry.txt` in the output directory the
grader provides (`MAKEFUN_OUTPUT_DIR`, `/output`, or local `out/`).
Standard library only; the line is 143 characters, inside the 200-char
limit, and a single line.
